
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a Hangman game while practicing Python strings, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Implement Hangman Game Logic

#### Description

Implement the Hangman game flow with secret word selection, letter guessing, and win/lose conditions.

#### Requirements

Completed program should:

- Randomly select a secret word from a predefined list
- Prompt the player to guess one letter at a time
- Display the current word progress as `_ _ _ _` with guessed letters revealed
- Track and display remaining incorrect guesses
- End when the word is guessed or attempts are exhausted

### 🛠️ Player Feedback and Game UI

#### Description

Show clear game updates and result messages after each guess.

#### Requirements

Completed program should:

- Show correct and incorrect letters separately
- Notify the player when a letter has already been guessed
- Display a win message when the player guesses the word
- Display a lose message with the correct word when attempts run out
